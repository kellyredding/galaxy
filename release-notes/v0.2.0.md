### 🛑 Stop ends the whole session
- Stopping a session now ends Claude Code and everything it started, not only the launcher in front of it. Before, a stopped persona session could keep running out of sight and keep writing to its conversation.
- If Claude Code outlasts the first signal, Galaxy follows up with firmer ones, even after the session's terminal has closed.
- Persona sessions need claude-persona 1.4.0, which hands its process over to Claude Code instead of staying in front of it.

### 🔁 Resuming never splits a conversation
- Before resuming, Galaxy checks whether another Claude Code process still holds the conversation (a terminal, a stray process, or a background worker) and offers to stop it first: "Session Is Still Open Elsewhere". Resuming a held conversation used to continue it in a new transcript, and the next resume reopened it as it stood before the move.
- A session whose conversation has already moved to a new transcript follows it there on its next resume.
- An idle background worker holding the conversation is now confirmed before it's stopped, rather than stopped silently.

### 🧠 A leaner Agents tab
- The Agents tab no longer keeps copies of every agent's prompt and reply. A long-running session's agent text, 11 MB on disk, once grew to about 225 MB in the app.
- The list carries only what a row shows, and an agent's full text loads when you open it.

### 🛠️ Fixes
- `galaxy <persona> -p` passes on Claude Code's exit status when a signal ends it, and `galaxy update` exits cleanly when interrupted, instead of printing a stack trace.
- The ledger names the signal when one of its extraction runs of Claude Code is killed.
- Running `bin/release` again finishes a release that stopped partway, instead of refusing because the tag exists.
