### 📦 Install and update with one command
- Galaxy now installs with a single script, which puts the CLI tools and Galaxy.app in place.
- `galaxy update` installs the latest release; `galaxy update --local` builds and installs your own checkout, uncommitted changes included, the same way.
- `galaxy doctor` checks that the installed tools and app came from one build, how the app is signed, and that only one copy of Galaxy receives `galaxy://` links.

### 🔏 Signed releases that keep their permissions
- Galaxy.app is signed with its own release certificate, so macOS keeps the permissions you've granted across updates instead of asking again after each one.
- The signing key lives in 1Password and is used only while a release is built; nothing is stored on the build machine.
- The ledger and artifacts tools no longer depend on Homebrew's OpenSSL, so a release runs on any Apple Silicon Mac with macOS 26.

### 💬 Reviews reach the agent intact
- A review is stored on the session's timeline, and the agent gets a short pointer to read it with `galaxy-timeline message`, so a long review is no longer cut off on its way in.
- A queued prompt that reached the agent cut off is detected, recorded in full, and handed over by pointer instead.

### 🔄 Steadier sessions
- When a resumed session's ready signal never arrives, Galaxy now releases it on its own, sending `/galaxy:resume` before its queued messages.
- The inbox can release a resumed session by hand, refusing only one that is mid-turn.
- A background process started from a Galaxy terminal no longer keeps sessions alive after Galaxy quits.

### 🧹 Snapshots retired
- The Snapshots tab, its reader, and the `galaxy-snapshots` tool are gone; artifacts cover what snapshots did.
- Handoffs after `/clear` no longer include saved snapshots. Existing snapshot data is left in place, and old snapshot events still show on the timeline.

### 🛠️ Fixes
- Two memory leaks are fixed: search boxes that left their pipelines behind, and failed git queries that left their timers and pipes behind.
- Every line in `galaxy.log` carries its date, and an app restart can no longer overwrite the outgoing app's lines.
- Builds of the app no longer register a second Galaxy.app that could take `galaxy://` links.
